One gzipped tar with a consistent snapshot of every database listed above and a manifest.json. The snapshots are taken through SQLite while the service keeps running; nothing is paused. The configuration and the interception CA are not included: they hold keys. The same archive from a shell, for a scheduled job: kompressor backup --out DIR.

To restore: stop the service, put stats.db and refs.db where the File column says, remove any -wal and -shm files beside them, and start it.
