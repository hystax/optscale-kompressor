Write-ahead log is what has been written and not yet folded into the file; SQLite folds it in by itself, and Checkpoint does it now. Schema is the version the file holds against the one this build expects. Reclaimable is space a vacuum would return to the disk. Check reads every page and every index and can take a while on a large file; its result is kept until the service restarts. From a shell: kompressor db status, kompressor db check, kompressor db checkpoint.

Restore

Restoring replaces the databases, so it is done from a shell on this host with the service stopped — not from this page. The command refuses a database that is still open, checks the archive in full before touching anything, and moves the files it replaces aside (…before-restore-<time>) instead of deleting them.
